# Agency Scope Estimator

A single `index.html` file. No build step, no dependencies.

## Preview
Double-click `index.html` to open it in your browser.

## Publish on Netlify (2 minutes)
1. Go to app.netlify.com → **Add new project → Deploy manually**.
2. Drag this `05_build` folder onto the page.
3. Rename the site under **Project configuration → Change project name**, e.g. `agency-scope-estimator`.

To publish via GitHub instead: create a repo, push this folder, and import it in Netlify
(no build command, publish directory `.`).

## Edit
- Services and hours: the `GROUPS` list in the `<script>` near the bottom
- Disciplines and default rates: the `DISC` list just above it
- Look and feel: colour tokens at the top of the `<style>` block
